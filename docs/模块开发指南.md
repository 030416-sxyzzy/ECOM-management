# 购物车管理和商品分类搜索模块开发指南

## 🎯 模块概述

### 购物车管理模块
- **功能**: 添加商品、修改数量、删除商品、查看购物车
- **数据表**: `cart_items` (已存在)
- **依赖**: 用户认证、商品信息

### 商品分类和搜索模块
- **功能**: 分类浏览、关键词搜索、商品筛选
- **数据表**: `categories`, `products` (已存在)
- **依赖**: 无外部依赖

## 📋 开发计划

### 第一阶段：商品分类和搜索 (1-2周)

#### 后端API设计
```java
// 商品分类控制器
@RestController
@RequestMapping("/api/categories")
public class CategoryController {
    
    // 获取所有分类
    @GetMapping
    public List<Category> getAllCategories();
    
    // 根据分类获取商品
    @GetMapping("/{categoryId}/products")
    public Page<Product> getProductsByCategory(@PathVariable Long categoryId);
}

// 商品搜索控制器
@RestController
@RequestMapping("/api/products")
public class ProductController {
    
    // 搜索商品
    @GetMapping("/search")
    public Page<Product> searchProducts(@RequestParam String keyword);
    
    // 获取商品详情
    @GetMapping("/{id}")
    public Product getProductById(@PathVariable Long id);
    
    // 获取热门商品
    @GetMapping("/hot")
    public List<Product> getHotProducts();
}
```

#### 前端页面设计
- 分类导航栏
- 商品搜索框
- 商品列表展示
- 商品详情页面

### 第二阶段：购物车管理 (1-2周)

#### 后端API设计
```java
// 购物车控制器
@RestController
@RequestMapping("/api/cart")
public class CartController {
    
    // 获取用户购物车
    @GetMapping
    public List<CartItem> getCartItems();
    
    // 添加商品到购物车
    @PostMapping("/add")
    public CartItem addToCart(@RequestBody AddToCartRequest request);
    
    // 更新购物车商品数量
    @PutMapping("/{itemId}")
    public CartItem updateCartItem(@PathVariable Long itemId, @RequestBody UpdateCartRequest request);
    
    // 删除购物车商品
    @DeleteMapping("/{itemId}")
    public void removeFromCart(@PathVariable Long itemId);
    
    // 清空购物车
    @DeleteMapping("/clear")
    public void clearCart();
}
```

#### 前端页面设计
- 购物车页面
- 购物车商品列表
- 数量调整控件
- 总价计算显示

## 🔧 技术实现要点

### 1. 数据库设计优化

#### 商品表查询优化
```sql
-- 为搜索添加全文索引
ALTER TABLE products ADD FULLTEXT(name, description);

-- 为分类查询添加索引
CREATE INDEX idx_category_status ON products(category_id, status);
```

#### 购物车表优化
```sql
-- 为用户购物车查询添加索引
CREATE INDEX idx_user_cart ON cart_items(user_id, created_at);
```

### 2. 缓存策略

#### Redis缓存设计
```java
// 商品信息缓存
@Cacheable(value = "products", key = "#productId")
public Product getProductById(Long productId);

// 分类信息缓存
@Cacheable(value = "categories")
public List<Category> getAllCategories();

// 购物车缓存
@Cacheable(value = "cart", key = "#userId")
public List<CartItem> getCartItems(Long userId);
```
